# Ketshopweb Skills

Skill สำหรับ AI Agent (Claude Code, Claude Desktop, Cursor, Codex และตัวอื่นที่รองรับ MCP) ให้ทำงานกับเว็บไซต์ร้านค้าบน **Ketshopweb** ได้ถูกวิธี: แก้หน้าเว็บ เพิ่ม Section / Element เขียน Ai section แปลภาษา จัดเมนู ปรับสไตล์ จัดการคลังรูป เขียนบทความ ดูตัวอย่าง และเผยแพร่ ผ่าน MCP ของร้านคุณเอง

## ติดตั้ง

```bash
# จาก GitHub
npx skills add Ketshopweb/skills

# ติดตั้งให้ทุกโปรเจกต์ สำหรับ agent ตัวเดียว
npx skills add Ketshopweb/skills -g -a claude-code
```

## Skill ใน repo นี้

| Skill | ใช้เมื่อ |
|---|---|
| `ketshopweb` | ต้องการให้ AI สร้าง แก้ แปล ปรับสไตล์ หรือเผยแพร่หน้าเว็บร้านบน Ketshopweb |

## เริ่มใช้งาน

1. **ต่อ MCP ของร้าน** (ครั้งแรกครั้งเดียว) แทน `<โดเมนร้าน>` ด้วยโดเมนหลักของร้านคุณ (ไม่ต้องมี `https://`)

   ```bash
   claude mcp add --transport http ketshopweb https://mcp.ketshopweb.com/<โดเมนร้าน>
   ```

   agent ตัวอื่นดู URL และตัวอย่างการตั้งค่าได้ที่หลังบ้านของร้าน: ปรับแต่ง › ขั้นสูง › MCP (คัดลอก URL จากหน้านั้นได้เลย)
2. **กดอนุญาต** เบราว์เซอร์จะเปิดหน้ากดอนุญาตของร้าน ให้เข้าด้วยผู้ใช้หลังบ้านที่เป็น administrator หรือ webmaster แล้วเลือกสิทธิ์ที่จะให้ AI
3. **สั่งงานเป็นภาษาคน** AI จะโหลด skill เองเมื่อคำขอเกี่ยวกับเว็บร้าน หรือเรียกตรง ๆ ด้วย `/ketshopweb`

```text
เพิ่ม Section แนะนำสินค้าขายดีในหน้าแรก ใต้แบนเนอร์ ใช้สีของร้าน
```

```text
แปลหน้า "เกี่ยวกับเรา" เป็นภาษาอังกฤษให้ครบทุก Section
```

```text
ทำ hero ของหน้าแรกใหม่ รูปเต็มจอ มีหัวข้อกับปุ่มไปหน้ารายการสินค้า แล้วส่งลิงก์ดูตัวอย่างให้ดูก่อน
```

```text
/ketshopweb เพิ่มเมนู "โปรโมชัน" ชี้ไปหน้าโปรโมชัน แล้วอัปเดตเว็บไซต์
```

## สิ่งที่ควรรู้

- **AI แก้ "ฉบับร่าง" ก่อนเสมอ** หน้าร้านจริงยังไม่เปลี่ยนจนกว่าจะเผยแพร่ คุณดูผลได้จากลิงก์ดูตัวอย่างที่ AI ส่งให้ (ใช้ได้ 30 นาที)
- **การเผยแพร่ต้องได้รับอนุญาตสองชั้น** คุณต้องติ๊กสิทธิ์ "เผยแพร่" ในหน้ากดอนุญาตเอง (ค่าตั้งต้นคือไม่ติ๊ก) และ AI ต้องแสดงรายการที่จะเปลี่ยนแล้วรอคุณตอบตกลงทุกครั้ง ถ้าไม่ให้สิทธิ์นี้ คุณกด "อัปเดตเว็บไซต์" ในหลังบ้านเองได้ตามปกติ
- **บางอย่างมีผลกับเว็บจริงทันที** เช่น ลบหรือแทนที่รูปที่หน้าเว็บใช้อยู่ ตั้งค่าหน้า ลบหน้า เผยแพร่หรือลบบทความ AI จะถามก่อนทำ
- **สิ่งที่ AI แก้ผ่านช่องทางนี้ไม่ได้** สินค้า หมวดหมู่ ราคา สต็อก ออเดอร์ ลูกค้า การชำระเงิน และการจัดส่ง ยังจัดการที่หลังบ้านเหมือนเดิม
- **ยกเลิกการเชื่อมต่อได้ทุกเมื่อ** ที่หลังบ้านของร้าน: ปรับแต่ง › ขั้นสูง › MCP
